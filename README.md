# BitNode

Node backend for [BitPanel](https://github.com/BitrateLLC/bitpanel), powered by sing-box or Xray-core.

> **Disclaimer**: This project is for educational and learning purposes only.

## Features

- Protocols: V2Ray family, Trojan, Shadowsocks, Hysteria2, TUIC, AnyTLS, with kernel-specific protocol support
- Sync: WebSocket push + REST polling dual channel
- User controls: speed limit, device limit, alive-IP tracking, hot update
- Deploy modes: node mode, machine mode, standalone mode
- Multi-instance: single process binding multiple panels / nodes

## Install on Linux

BitNode runs directly on the host under systemd; Docker and Docker Compose are not required.

### Installer

```bash
# Node mode
curl -fsSL https://raw.githubusercontent.com/BitrateLLC/bitnode/dev/install.sh | \
  sudo bash -s -- --mode node --panel https://panel.example.com --token TOKEN --node-id 1

# Machine mode
curl -fsSL https://raw.githubusercontent.com/BitrateLLC/bitnode/dev/install.sh | \
  sudo bash -s -- --mode machine --panel https://panel.example.com --token TOKEN --machine-id 1

## xbctl

Run `xbctl` after installation for help. Common commands:

```bash
xbctl list                          # list all instances
xbctl status                        # running status
xbctl bind add-node --panel URL --token TOKEN --node-id 1
xbctl bind add-machine --panel URL --token TOKEN --machine-id 1
xbctl bind remove-node --panel URL --node-id 1
xbctl service restart
```

## Configuration

Legacy single-panel config is fully compatible. Set `kernel.type` to `singbox` (default) or `xray`; Xray is useful for transports such as XHTTP that sing-box does not support. Appending bindings auto-migrates to `instances` format. See `config.yml.example`.
